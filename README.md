# Customer Segmentation & Churn Pattern Analytics in European Banking

Interactive Streamlit dashboard based on the provided `Customer-Churn-Records.xlsx` dataset.

## Features

- Overall churn KPI dashboard
- Geography-wise churn analysis
- Gender and geography comparison
- Age-group analysis
- Credit-tier analysis
- Tenure analysis
- Number-of-products analysis
- Balance-status analysis
- High-value customer churn analysis
- Active vs inactive customer comparison
- Complaint vs churn analysis
- Interactive sidebar filters
- Filtered-data download

## Run locally

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install the requirements:

```bash
pip install -r requirements.txt
```

4. Start the app:

```bash
streamlit run app.py
```

5. Streamlit will open the dashboard in your browser.

## Deployment

The project can be deployed using Streamlit Community Cloud after the files are uploaded to GitHub.
